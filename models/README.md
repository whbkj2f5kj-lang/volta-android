# Mercedes-Benz W204 – Schwarz / Volta

Bearbeitete GLB: schwarzer Lack, ueberarbeitete Materialien, bereinigte Karosserievarianten und vier vollstaendige Raeder. Keine Draco-Kompression, damit der Qt-Importer sie direkt lesen kann.

## Import

ZIP entpacken und `w204_black_refined.glb` in Voltas 3D-Fahrzeugauswahl laden. Falls Voltas gespeicherte Lackfarbe das Schwarz ersetzt, in Volta Schwarz waehlen. Die Teile-Zuordnung fuer dieses neue Modell neu pruefen.
